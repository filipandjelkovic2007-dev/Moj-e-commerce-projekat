# Moj e-commerce projekat

Jednostavan e-commerce projekat napravljen u HTML, CSS i JavaScript, sa ciljem da prikaže funkcionalnost online prodavnice i korisničkog iskustva kupovine.

## Opis projekta
Ovaj projekat predstavlja mockup web prodavnice sa:
- stranicom za prijavu korisnika
- pregledom proizvoda
- detaljima o artiklima
- procesom kupovine
- potvrdom narudžbe

Projekat je fokusiran na vizuelni dizajn, responzivnost i jednostavnost korišćenja, bez korišćenja backend-a ili baze podataka.

## Tehnologije
- HTML
- CSS
- JavaScript
